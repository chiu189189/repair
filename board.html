手機不開機、別家說沒救？
帶來給我們看看

不開機、沒訊號這類問題，很多時候只是主機板上一顆小零件壞掉。我們用顯微鏡找出真正壞掉的地方，能修小零件就不換整片主機板。

有這些狀況嗎？

  • 不開機沒畫面、充電沒反應，或卡在蘋果標誌
  • 一直重開機開到一半就重開，反覆循環
  • 無訊號、無服務插卡沒訊號，或 Wi-Fi、藍牙打不開
  • 摔過、泡水後故障外觀沒事但功能壞了，或換了零件還是不能用

什麼是「晶片級維修」？

手機的主機板上有上千個小零件：晶片、電容、電阻，還有比頭髮還細的線路。手機不開機，往往只是其中一個零件壞掉或一條線斷掉。

很多店遇到主機板問題只能整片換，或直接說沒救。晶片級維修就是在顯微鏡底下找出那一顆壞掉的零件，只把它拆下來換新，讓整片主機板復活。

我們會做的維修

  • 更換晶片、電容找出短路、燒毀的零件，拆下換新
  • 飛線線路斷掉、焊點掉了，用極細的銅線把它接回去
  • CPU 重植摔機後 CPU 底下的焊點裂開，把 CPU 拆下重新植錫、焊回去
  • 充電、開機電路充不了電、開機排線正常卻不開機，查主機板上的電路

我們怎麼找出問題

  1. 量電流接上電源供應器，看手機開機時的電流，判斷大概卡在哪一段。
  2. 對照電路圖用主機板電路圖和點位圖，找出那一段電路上的零件。
  3. 顯微鏡下量測一個一個量，找到真正壞掉的零件。
  4. 報價，您同意才修告訴您壞在哪、怎麼修、費用多少。
  5. 修好、完整測試再交機開機、充電、訊號、相機等功能都測過一輪。

修好的話，資料還在嗎？

晶片級維修是修原本的主機板，不是換一片新的，所以修好後資料通常都還在。這也是為什麼很多客人寧願修主機板：照片、LINE 紀錄都捨不得丟。

主機板受損程度不同，無法保證每一台都能修好。不開機、進水、主機板的檢測需要拆機量測，檢測後決定不修酌收 NT$300；修不好不收維修費。詳見 維修服務條款。

常見問題

別家說要換主機板或沒救，你們還能修嗎？

很多「沒救」其實是那家店沒有做晶片級維修。帶來給我們檢測，能不能修、大概多少錢，檢測後會跟您說清楚。

修主機板要多久？

要看故障的位置和難度，簡單的當天可以完成，複雜的需要幾天。檢測後會跟您說預計時間。

Face ID 壞了可以修嗎？

Face ID 的零件跟主機板綁定，損壞時不一定能修復，要看是哪個部分壞掉。檢測後會告訴您能不能修。

不是 iPhone 也能修嗎？

可以。三星、OPPO、vivo、小米、Google、華碩等 Android 手機的主機板，我們也有在修。
